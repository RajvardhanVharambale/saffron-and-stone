
# Images — Saffron & Stone

This folder contains the image assets used throughout the Saffron & Stone restaurant website.

## Purpose

The images help create a visually appealing and engaging experience by showcasing the restaurant's atmosphere, food, and culinary preparation.

## Image Categories

- **Restaurant Interior:** Images showcasing the restaurant's dining space and ambience.
- **Chef & Kitchen:** Images highlighting food preparation and culinary craftsmanship.
- **Food & Menu:** Images of salads, pasta, pizza, desserts, and other featured dishes.

## Usage

Images are referenced in the HTML files using relative paths.

Example:

```html
<img
    src="images/fresh-salad.jpg"
    alt="Fresh seasonal garden salad"
>
```

## Image Guidelines

- Use descriptive filenames.
- Prefer optimized JPG, PNG, or WebP images.
- Maintain appropriate image dimensions and aspect ratios.
- Include meaningful alternative text for accessibility.
- Ensure image paths match the actual filenames.
