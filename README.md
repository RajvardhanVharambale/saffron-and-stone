

# Saffron & Stone — Restaurant Website

A modern, responsive restaurant website created as part of **Week 4 of my web development internship**. Saffron & Stone presents a restaurant’s atmosphere, story, menu, and contact information through a clean and user-friendly interface.

## 🌐 Project Links

- **Live Website:** [https://rajvardhanvharambale.github.io/saffron-and-stone/](https://rajvardhanvharambale.github.io/saffron-and-stone/)
- **GitHub Repository:** [https://github.com/RajvardhanVharambale/saffron-and-stone](https://github.com/RajvardhanVharambale/saffron-and-stone)

## 📌 Project Overview

Saffron & Stone is a multi-page restaurant website designed to provide visitors with an engaging online experience. It showcases the restaurant’s identity, food offerings, dining atmosphere, and contact details.

The website focuses on responsive design, intuitive navigation, visual presentation, and basic client-side form validation.

## ✨ Features

- **Responsive Design:** Adapts to desktop, tablet, and mobile screen sizes.
- **Multi-Page Website:** Includes Home, About, Menu, and Contact pages.
- **Restaurant Introduction:** Highlights the restaurant’s identity and atmosphere.
- **Menu Showcase:** Displays featured dishes with images and descriptions.
- **Interactive Navigation:** Provides navigation between website pages.
- **Contact Form:** Includes client-side validation for user input.
- **Visual Design:** Uses food and restaurant imagery to create an engaging experience.
- **Image Organization:** Keeps website images organized in a dedicated folder.

## 🚀 Getting Started

You can view the website directly using the live link, or run it locally.

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/RajvardhanVharambale/saffron-and-stone.git
   ```

2. Open the project folder:

   ```bash
   cd saffron-and-stone
   ```

3. Open `index.html` in your browser.

   Alternatively, open the folder in Visual Studio Code and use the **Live Server** extension to preview the website.
